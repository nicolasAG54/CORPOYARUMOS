### Modelo de ficha de proyecto

Cada proyecto debe almacenar:

- `title`, `slug`, `summary`, `status`.
- `startDate`, `endDate`, `referencePeriod`.
- `contractCode`, `contractValue`, `currency`.
- `partners[]`, `funders[]`, `roles[]`.
- `department`, `municipalities[]`, `veredas[]`, coordenadas solo cuando sea seguro.
- `participants.value`, `participants.unit`, `participants.scope`, `participants.source`.
- `challenge`, `approach`, `activities[]`, `outputs[]`, `outcomes[]`, `lessons[]`.
- `sources[]`, `documents[]`, `gallery[]`, `imageCredits[]`.
- `contentStatus`, `reviewedAt`, `reviewedBy`.
